# WhatsApp Bot Analytics

Ferramenta para análise de dados de atendimento de bots WhatsApp, desenvolvida em Streamlit.

## Funcionalidades

- Processamento de arquivos CSV com dados de atendimento
- Extração automática de tags de mensagens
- Análise de métricas como usuários únicos e taxa de recontato
- Geração de relatórios em Excel com tabelas e gráficos formatados
